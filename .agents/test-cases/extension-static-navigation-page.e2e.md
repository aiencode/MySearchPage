# 插件静态导航页：原页完整迁移测试用例

## 权威范围

- 行为和视觉基线：工作区根目录的 `mysearch.html`、`SiteUrls.json`、`pinyin_dict_firstletter.js`。
- 插件必须完整迁入原页的所有非 Gitee 用户可观察能力：页面结构与排版、站点配置、搜索、快速搜索、全部快捷键、历史、设置表格、导入导出和 UA 规则导出。
- 唯一删除对象是 Gitee：历史上传/下载、网站配置上传/下载、备份设置、Gitee 设置模态框、`giteeConfig`、令牌存取和所有 Gitee 网络请求。不得用新的 generic sync、endpoint 或 token UI 替代。
- 不新增 URL 协议白名单或其他改变原页配置接受范围的规则；除 Gitee 外，以原页实际行为为准。
- Canonical 页面是 `extension/navigation/navigation.html`：它既是 MV3 `chrome_url_overrides.newtab` 的入口，也是直接打开的静态备用入口。不得维护一份功能退化的第二页面。

## 对照方法

使用两个干净且相互隔离的 Chromium 用户资料：资料 A 打开原 `mysearch.html`，资料 B 加载解压后的插件并打开新标签或 `navigation/navigation.html`。对每个 TC 先建立相同本地数据，再按相同顺序操作。保留截图、地址栏、下载文件、焦点序列和操作前后数据；不要把源代码或存储实现细节当作人工通过依据。

## TC-MIG-001：新标签和直接入口是同一份完整导航页

- 步骤：在资料 B 分别新建标签页、直接打开 `navigation/navigation.html`；在每个入口完成搜索、打开设置、修改后重开。
- 期望：两种入口的全部控件、初始数据、行为和保存状态一致；均不是展示型占位页。

## TC-MIG-002：原页结构与三档响应式排版保真

- 步骤：在 769px、768px、480px 宽度下对照固定头、搜索框、控制按钮、动态站点按钮、历史区、快速搜索、设置模态框和表格。
- 期望：除 Gitee 按钮外，控件集合、顺序、文字、边框、状态样式、可滚动区域、断点和间距与原页一致；桌面/移动/超小屏均使用原页布局。

## TC-MIG-003：默认站点、导入配置与重开完整保真

- 步骤：比较首次默认站点；导入一份原页导出的配置；新增、编辑、拖拽排序后保存并重开。
- 期望：`siteUrls`、`buttonConfig.isSmall`、`siteFlags.rightClick`、三态 mode、`desktopMode`、顺序和站点按钮行为逐项与原页一致；不要求后端。

## TC-MIG-004：主搜索、空关键词与多选批量搜索等价

- 步骤：用中文/空格关键词分别执行单站搜索、右键或空格多选后 Enter 批量搜索、普通站点空关键词和需要关键词站点空关键词。
- 期望：目标地址、关键词传递、打开集合、提示、历史写入和每站空关键词分支与原页一致。

## TC-MIG-005：快速搜索保留中文、拼音、多词、光标与激活

- 步骤：桌面中未聚焦输入框时直接键入；在快速搜索框输入汉字、拼音首字母和多词；用方向键、Tab/Ctrl+Tab 与 Enter 操作匹配项。
- 期望：匹配集合、历史隐藏、蓝色匹配高亮、绿色光标高亮、焦点和滚动位置、Enter 激活结果与原页一致；拼音字典不能退化为普通文本包含搜索。

## TC-MIG-006：全局快捷键逐项等价

| 输入 | 原页等价结果 |
| --- | --- |
| `Ctrl+F3` / `Ctrl+F5` / `Ctrl+F6` / `Ctrl+F9` / `Ctrl+F10` | 分别按名称、时间、长度、首次时间、次数排序 |
| `F7` | 聚焦主搜索框并恢复原页光标策略 |
| `F8` / `Ctrl+Delete` | 清空主搜索并聚焦 |
| `Ctrl+-` | 取消当前多选 |
| `Tab` / `Ctrl+Tab` | 按原页方向在站点与历史区域跳转 |
| 空格 | 在非输入框焦点上选择/取消当前站点或历史 |
| `Enter` | 按当前状态激活匹配、批量搜索、单站搜索或回填历史 |
| `F2` / `Delete` / `Ctrl+Z` | 编辑当前历史、删除当前/选中历史、撤销删除 |

通过条件：逐项按两个资料实际操作，观察到的焦点、数据和页面结果均与原页一致，且不会被浏览器默认操作替代。

## TC-MIG-007：主页面 Escape 状态机与移动 Esc 一致

- 步骤：分别在历史编辑、主搜索聚焦、快速搜索有文本、快速搜索仅保留匹配以及普通状态下连续按 Escape；移动端点击 `mobile-esc-btn`。
- 期望：依次执行原页的退出编辑、主搜索失焦、快速搜索文本清空但匹配暂留、再清除匹配；移动按钮进入同一状态机。

## TC-MIG-008：历史完整行为等价

- 步骤：建立不同名称、时间、长度、首次时间和次数的历史，依次使用五个排序入口/快捷键、编辑历史模式、F2、Delete、Ctrl+Z、导入和导出。
- 期望：历史标签、排序、编辑确认/取消、批量删除、撤销和导出/导入兼容格式均与原页一致。

## TC-MIG-009：设置表格、本地文件与 UA 导出等价

- 步骤：打开设置，新增/选中/删除行，切换右键、三态单开和桌面/手机状态；过滤表格、拖拽行和列，保存，执行本地配置导入/导出与 UA 规则导出。
- 期望：表格列、二态/三态控件、拖拽、过滤、站点按钮重建、本地持久化和 UA 输出与原页一致。

## TC-MIG-010：设置窗口快捷键与 Escape 状态机等价

- 步骤：设置窗口中分别使用普通字符、Backspace、F8、四个方向键、Enter 和连续 Escape。
- 期望：筛选、线性/跨列表格导航、保存，以及“先失焦、再清筛选、最后关闭”的 Escape 顺序与原页一致；事件不得泄漏给主页面。

## TC-MIG-011：Gitee 和代用品彻底移除

- 检查：可见页面、设置操作、导航资源、localStorage/IndexedDB 键和浏览器网络记录。
- 禁止项：`sync-gitee`、`sync-from-gitee`、`gitee-config`、`upload-sites-config`、`download-sites-config`、`giteeConfig`、Gitee 模态框、Gitee API 请求，以及替代性的 `sync-button`、`sync-form`、endpoint/token/syncExecutor 配置。
- 期望：上述项均不存在；TC-MIG-003 至 TC-MIG-010 的本地功能仍可完成，无缺失元素异常。

## 自动化与人工验证分工

- Node 回归测试验证：canonical 页面与资源、原 CSS/默认数据/拼音资产迁入、原页非 Gitee 事件绑定和关键函数、每个快捷键分支与关联调用、设置/历史/快速搜索状态机资源、逐项 Gitee 排除。
- 浏览器差分验证：本文件 TC-MIG-001 至 TC-MIG-011 的真实点击、焦点、拖拽、地址栏、下载、响应式视觉和持久化结果。Node 静态或受控 DOM 测试不能替代此证据。
- 运行 Node 回归：`node --test tests/extension-static-navigation.test.js`。
