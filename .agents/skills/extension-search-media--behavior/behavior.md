# 搜索结果媒体

## 用户行为

扩展对哔哩哔哩、抖音、YouTube、小红书的已识别搜索结果卡片隐藏图片、封面、头像和视频预览。四站默认开启。设置页“搜索结果图片与预览”区域提供四站“隐藏”复选框，修改后自动保存并通知已打开页面。

隐藏时收起媒体区域，保留原有标题、作者、摘要、统计、时长等文字和文字入口。不改写链接目标，不拦截原有文字入口的点击。不请求额外结果、不模拟滚动或点击加载更多；原站因布局变化自行触发的懒加载不由扩展控制。

已识别结果视频暂停、静音并关闭 autoplay。再次触发播放时继续抑制。主动打开的详情页和详情弹窗不受媒体隐藏控制，允许观看；详情遮罩后原有搜索结果继续隐藏。节点移出受控区域或关闭当前站开关时恢复扩展修改的样式、静音及 autoplay 状态，播放开始时间交由用户或原站决定。

功能独立于 UA 总开关、单站 UA enabled 和 uiTransform，不修改 UA 配置，不刷新页面。非搜索页面及结果区域外的账户标识、导航等媒体不属于处理范围。

## 识别与布局

`search-media-adapters.js` 定义站点的搜索路径、结果根节点、卡片、媒体容器、文字覆盖层、预览和详情边界。`search-media-controller.js` 只在匹配范围内执行可撤销 DOM 样式与媒体状态修改。

| 站点 | 搜索路径 | 主要结构 |
| --- | --- | --- |
| 哔哩哔哩 | `search.bilibili.com` 或 `/search` 路径 | `.bili-video-card` 等视频、用户、直播和番剧卡片 |
| 抖音 | `/search` 路径 | 搜索 `data-e2e` 卡片、搜索结果列表的 `li` 及具名搜索卡片 |
| YouTube | `/results`、`/search` 路径 | 桌面 YTD 和移动 YTM 结果、频道、播放列表、Shorts 卡片 |
| 小红书 | `/search_result`、`/search` 路径 | `.note-item`、带 `data-note-id` 的 section 及搜索用户卡片 |

选择器的完整列表以适配器为准。已识别结果根节点存在时，普通结果卡片必须位于其内；不存在时使用搜索路径与卡片结构组合识别，同时排除详情、header、nav、aside 等区域。非搜索路径仅保留已处理过的背景卡片，且需要可见的站点详情遮罩或含视频的通用对话框。

纯媒体容器隐藏；同时含文字的封面容器解除高度和比例约束，将定位文字恢复到正常布局。B 站空骨架隐藏，真实卡片内容恢复正常流，统计文字不随封面消失。小红书已识别笔记结果容器使用可撤销的 flex 换行布局，解除卡片绝对定位和旧位移；间距按桌面、≤768px、≤480px 使用 6px、2px、1px。

抖音复用搜索封面作为详情挂载容器时，活动详情的祖先容器撤销扩展持有的隐藏与布局覆盖，保留原站定位及高度；祖先内的背景预览仍分别隐藏和暂停。详情关闭或移除后重新收起空封面，缓存详情的按钮/标题不计入结果文字，避免留下拦截下一次点击的空壳。原站的 hidden、aria-hidden 和关闭样式不被强制改成可见。

搜索入口替换模块也必须保留详情挂载边界：抖音输入框与提交按钮之外的无标识祖先可能是后续详情 portal 的复用容器，不能仅因当前没有视频或关闭按钮就整体替换。`native-search-redirect-runtime.js` 只允许向明确匹配搜索 owner 标识的外层容器提升替换边界。该约束独立于媒体隐藏开关；媒体隐藏关闭时仍必须保证连续点 × 关闭/重新打开详情正常。

样式按属性保存原值和优先级。仅撤销扩展仍持有的覆盖值；原站在隐藏期间更新的样式作为新的恢复值保留。详情遮罩先关闭、搜索 URL 稍后恢复时，背景结果状态按详情路径连续保持，避免图片闪现和瀑布流重复重排；只有恢复搜索路径或明确转到另一非搜索路径时才撤销保护。DOM 增删、文字与相关属性变化、媒体事件、路由及页面恢复事件触发重新判定；URL 每 250ms 检查一次变化，以覆盖隔离世界无法可靠拦截的站内 history 调用。

## 存储与接入

`chrome.storage.local.searchMediaSettings` 是基础域名到布尔值的对象，允许部分存储：

```json
{
  "bilibili.com": false,
  "douyin.com": true,
  "youtube.com": true,
  "xiaohongshu.com": true
}
```

仅明确的 `false` 表示关闭；无对象、缺少站点或其他值均按开启规范化。`SearchMediaSettings` 提供 `storageKey`、`sites`、`normalize`、`read`、`setEnabled`、`subscribe`。单页写操作串行，每次写前读取当前对象并只合并目标站值。存储变化通过 `chrome.storage.onChanged` 同步，异步初读不会覆盖已收到的新状态。

内容脚本在四站域名及子域名的 `document_start` 依次加载共享设置、适配器和控制器。设置页依次加载共享设置与设置区脚本。新增功能没有运行时外部依赖。

设置区读取完成前禁用控件，保存期间禁用相应站点；保存失败后回到当前已存储状态并显示失败信息。站点复选框在桌面、≤768px、≤480px 的尺寸分别为 18px、20px、18px，区域间距为 6px、2px、1px。

普通 Service Worker 唤醒及浏览器启动时，后台只向已打开的四站顶层标签重新注入现有三个搜索媒体脚本，不探测阻断版本、不刷新页面；页面标记缺失或过期也不触发刷新。MV3 后台闲置终止后会被页面消息重新唤醒，不能将每次顶层代码执行都视为扩展升级。仅扩展安装/更新事件允许检查四站标签，并刷新不兼容或已失效的标签以清除驻留旧脚本。设置页显式“重连旧标签”检查全部 HTTP(S) 标签；健康条件必须同时满足 DOM 版本标记、当前隔离世界初始化成功标记 `__mySearchBlockingRuntimeVersion` 和规则模块存在，不能仅凭扩展重载后仍残留的 DOM 标记认定脚本存活。非四站且运行健康的页面不刷新，也不注入媒体脚本。`reconnectSearchMediaTabsBG` 使用独立的 `includeAllSites` 与 `allowRuntimeReload` 选项，均默认 `false`，不得以重连范围隐式授权刷新。

当前阻断运行标记为 `immediate-rule-blocking-v4`（扩展 1.0.7）。控制器使用实例标记避免同一隔离世界重复安装，并将自身持有的行内样式、静音和 autoplay 原值保存为 DOM 账本，以便扩展重载后安全接管和撤销。正常 SPA 导航提交后同步更新阻断状态，不依赖延时或额外派发 popstate。媒体隐藏本身仍只作用于四站搜索结果，不因显式重连扩大处理范围。更改媒体开关不会刷新页面。以下行为均由现有后台和控制器承担，没有第二套规则系统。

## 详情切换与搜索浮层隔离

- SPA 切换内容时，尚未更新的旧页面标题不能归属给新内容；以内容编号判断标题归属，同一详情仅改变 query/hash 不视为换内容。相同标题只有在当前内容编号下的自身标题节点也明确命中时才可作为新详情证据，不读取推荐区或其他编号的预加载内容作为佐证。
- 标题来源的页面门禁必须随当前标题命中证据失效而清除；明确的搜索词、目标 URL、作者和卡片规则仍即时生效，不通过延时或关闭拦截规避误拦。
- 详情关闭且可见结果流已经恢复时，残留详情 URL 不再代表当前内容；点击或导航到明确命中的目标地址仍单独阻断。
- 页面状态测量临时忽略扩展自己对正文施加的 `visibility:hidden` CSSOM 声明，并同步恢复，避免把门禁遮挡误读成详情关闭；不修改 DOM 属性，不触发原站路由或观察器。
- 原生搜索浮层清理不得删除已识别的正文详情根、详情后代或承载详情的共同外壳。正文含“热榜”“猜你想搜”等文字不是删除详情的依据；明确搜索浮层选择器命中时，同样保护承载详情的外壳。

## 小红书直接帖子入口的历史回收

- 直接加载或刷新 `/explore/:noteId` 后，关闭原帖时小红书会用 `replaceState` 将当前历史项归位到 `/explore`；普通卡片帖子关闭则会真实后退。不能静默取消前一次归位，留下站点内部路由已回列表而浏览器历史仍指向原帖的分裂状态。
- 仅在小红书同源、详情已关闭且可见列表背景已挂载时，允许这次原生 `replaceState` 完整写入 URL 和原站全部 state。扩展不伪造 `back/current/position`，不事后只改地址，也不添加多余历史项。
- 该许可仅属于当前文档中已返回的背景地址，不持久化为站点权限。明确的 URL 规则继续优先，详情仍可见、没有列表背景、跨源、普通首页点击或 `window.open` 均不能使用此例外；重新加载首页文档仍按首页权限阻断。规则更新清除这份文档内背景许可。
- 路由诊断只读采样历史 `current/back/forward` 的 pathname、position 和最多六条近期拒绝记录，不输出历史链接的 query/hash 或帖子校验参数；采样继续跳过无痕和已丢弃标签。
